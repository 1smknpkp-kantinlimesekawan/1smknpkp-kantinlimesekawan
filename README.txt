KANTIN LIME SEKAWAN — FILE DIPISAH PER HALAMAN

Daftar file:
- index.html       : Beranda, promo, menu populer
- menu.html        : Halaman menu dan filter kategori
- cara-pesan.html  : Panduan cara pesan
- pencarian.html   : Pencarian menu
- keranjang.html   : Keranjang, jumlah, total, konfirmasi pesanan demo
- profil.html      : Profil siswa
- masuk.html       : Form masuk demo
- style.css        : Desain bersama untuk semua halaman
- script.js        : Fungsi bersama: tambah keranjang, filter, pencarian, profil, dan pesanan demo

CARA MEMBUKA:
1. Extract ZIP.
2. Buka VS Code -> File -> Open Folder -> pilih folder ini.
3. Buka index.html dan jalankan dengan Live Server. Bisa juga klik dua kali index.html untuk membuka di browser.
4. Jangan pindahkan file HTML dari style.css dan script.js; semuanya perlu berada dalam folder yang sama.

Catatan: Login dan checkout hanya simulasi front-end. Data demo disimpan di localStorage browser dan tidak dikirim ke kantin/server. Foto menu dan font mengambil sumber online sehingga perlu internet.
